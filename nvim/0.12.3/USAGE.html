IntelliJ 사용자를 위한 Neovim 0.12.3 완벽 가이드

JetBrains IntelliJ IDEA에서 Neovim으로 성공적으로 안착하기 위한 1:1 단축키 치트시트 및 실전 개발 가이드입니다.

📌 핵심 개념: 리더 키 (<leader>)

이 설정에서 <leader> 키는 스페이스바 (Space)로 설정되어 있습니다.
예를 들어 Space를 누른 뒤 f, f를 순서대로 누르면 전체 파일 검색 창이 열립니다.

💡 Tip (which-key 단축키 힌트): Space를 누르고 약 0.3초간 기다리면, 화면 하단에 현재 누를 수 있는 모든 단축키 목록이 팝업으로 자동 표시됩니다. 굳이 모든 키를 외우지 않아도 손쉽게 탐색할 수 있습니다!

📂 영역별 핵심 조작 가이드

📁 1. 파일 탐색기 내부 조작 (NvimTree)
  • a : 새 파일 생성 (이름 끝에 /를 붙이면 폴더)
  • d : 파일 또는 폴더 삭제
  • r : 이름 변경 (Rename)
  • x / c / p : 잘라내기 / 복사 / 붙여넣기
  • o 또는 Enter : 파일 열기
  • q : 탐색기 닫기
🪟 2. 창 분할 및 탭 관리 (Splits)
  • Space s v : 세로 창 분할 (Vertical Split)
  • Space s h : 가로 창 분할 (Horizontal Split)
  • Space s m : 현재 창 최대화 / 이전 크기 복원 토글
  • Space s x : 현재 창 닫기
  • Ctrl + h / j / k / l : 방향키처럼 분할 창 사이 이동
✂️ 3. 텍스트 감싸기 & 빠른 조작 (Surround)
  • ysiw" : 현재 단어를 큰따옴표로 감싸기
  • cs"' : 큰따옴표를 작은따옴표로 변경
  • ds" : 감싸고 있는 따옴표 제거
  • siw : 클립보드에 복사된 내용으로 단어 대체
  • jk : Insert 모드에서 빠른 Esc 탈출
💾 4. 세션 관리 & 작업 저장
  • Space w s : 현재 열린 창/버퍼 세션 저장 (Save Session)
  • Space w r : 이전 작업 공간 세션 복원 (Restore Session)
  • Space n h : 검색 후 남아있는 하이라이트 지우기
  • Space f t : 프로젝트 내 모든 TODO 주석 조회
